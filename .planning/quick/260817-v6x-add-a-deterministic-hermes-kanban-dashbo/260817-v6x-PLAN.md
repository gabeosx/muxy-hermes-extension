# Goal

Provide a test-only Hermes Kanban dashboard fixture that exercises the exact authenticated REST contract used by the Muxy board tab, then prove the built extension works through Muxy's native UI with Computer Use.

# Tasks

1. Add a loopback-only, bearer-authenticated Kanban fixture with seeded columns/cards and bounded in-memory create/status mutations.
2. Add automated fixture contract tests and a runnable fixture command; rebuild and validate the extension.
3. Start the fixture, reload the unpacked extension in Muxy, and use Computer Use to prove connection, rendering, card creation, card movement, and constrained-pane scrolling.

# Acceptance

- The fixture binds only to `127.0.0.1`, requires a fixed test-only bearer, validates the board slug, and exposes only the three Kanban routes consumed by the extension.
- Seed data contains multiple populated columns without secrets or filesystem paths.
- Automated tests verify authentication, board loading, task creation, status mutation, and rejection of unknown routes/boards.
- The built extension connects to the running fixture inside Muxy and visibly completes a create-and-move workflow.
