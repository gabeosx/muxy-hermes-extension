# Authenticate first, then choose a Hermes board

The board tab now asks only for a Hermes Dashboard address before sign-in. After Hermes verifies the user session, it retrieves the authenticated board catalog, selects a safe default deterministically, and waits for an explicit **Open board** action.

## Completed work

- Added an authenticated, unscoped `GET /api/plugins/kanban/boards` client path that retains only bounded picker fields and rejects malformed or unauthorized responses.
- Added a deterministic fixture catalog, including internal fields that the client intentionally drops at the request boundary.
- Replaced the pre-auth board-name field with a signed-in board picker, empty-catalog state, and explicit open action.
- Restored sessions now reverify, refresh the catalog, retain a saved board only when still available, and return to the picker rather than opening a board automatically.
- Persisted Dashboard sessions can temporarily have no selected board; credentials remain transient and session expiry clears stored Dashboard data.
