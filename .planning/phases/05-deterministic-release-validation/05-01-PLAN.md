# Phase 5 Plan 01: Build the Deterministic Release Gate

## Objective

Replace historical evidence validation with one current-architecture gate that verifies clean installs, tests, import reachability, secrets, permissions, marketplace assets, Node compatibility, and reproducible distributions.

## Tasks

1. Validate the production entry import graph and fail on unreachable or forbidden legacy modules.
2. Validate the least-privilege manifest, marketplace asset dimensions, README, static SVG safety, and exact distribution allowlist.
3. Add bounded secret scanning and npm audit high/critical enforcement.
4. Run two isolated clean copies through `npm ci`, two no-retry test passes, and deterministic builds, comparing complete distribution digests.
5. Record sanitized diagnostics, always remove temporary copies, and expose a fast structural mode for unit coverage.

## Verification

- Node 20+ prerequisite is explicit and runtime dependencies remain empty.
- The complete clean-copy gate succeeds from path-independent temporary roots.
- Two distribution inventories and SHA-256 maps are identical.
- No temporary root remains after pass or failure.
