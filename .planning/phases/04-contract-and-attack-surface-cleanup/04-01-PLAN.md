# Phase 4 Plan 01: Align the Marketplace Product Contract

## Objective

Make the source, manifest, bundle, tests, and user documentation describe only the shipped password-authenticated Dashboard session and WebSocket architecture.

## Tasks

1. Rename the extension identity, add marketplace metadata and Node compatibility, and keep only current permissions.
2. Reduce the curl relay to the current authenticated Dashboard request contract, remove dynamic DOM HTML support, and make unsupported OAuth/OIDC states explicit.
3. Prove the production import graph and delete unreachable bearer/SSE/recovery product code, fixtures, validators, evidence, and tests while preserving archived planning artifacts.
4. Add release support, security, privacy, permissions, troubleshooting, compatibility, and uninstall documentation.
5. Build and run the remaining current-architecture tests, then validate the exact distribution surface.

## Verification

- Production entries reach only current Dashboard, operations, board, Muxy surface, and static icon modules.
- Passwords and tickets are absent from persistence, argv, URLs after WebSocket construction, bundles, and docs examples.
- OAuth/OIDC-only provider states are visibly unsupported.
- The build contains no public historical evidence and requests no file/background authority.
- Current behavioral and packaging tests pass.
