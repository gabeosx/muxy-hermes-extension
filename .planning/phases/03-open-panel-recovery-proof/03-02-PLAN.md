## Trust Boundaries

| Boundary | Description |
|---|---|
| fixture/proxy observations → public recovery evidence | Content-bearing transport data must become only allowlisted structural facts. |
| simulation scenario → deployment matrix | A simulated behavior cannot establish the deployment class it resembles. |
| test proxy → pinned Gateway | The proxy receives bearer/content transiently and must stay loopback-only, fixed-route, and nonlogging. |
| native harness → local machine | Docker, ports, temp homes, journals, and Muxy state are external test resources requiring exact cleanup. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-02-01 | Information disclosure | recovery fixture and renderer | high | mitigate | Enforce exact schemas, reject content-bearing keys/values, and run high-entropy sentinel scans over source, dist, evidence, and command output. |
| T-03-02-02 | Spoofing | simulated topology verdicts | high | mitigate | Hard-code remote analogues to Unverified and separate named scenario from observed behavior and deployment label. |
| T-03-02-03 | Tampering | versioned observation | high | mitigate | Validate version tuple, schema version, fixed enums, safe shape hashes, actual-observation state, and cleanup before publication. |
| T-03-02-04 | Elevation of privilege | test interruption proxy | high | mitigate | Keep it test-only, loopback-bound, fixed-upstream/fixed-route, dependency-free, nonlogging, and absent from the extension manifest/bundle. |
| T-03-02-05 | Denial of service | disposable fixture lifecycle | medium | mitigate | Allocate unique ports and exact temp roots, bound waits, stop all processes, and fail evidence publication if cleanup verification fails. |
