# Phase 6 Plan 01: Disposable Real-Topology Qualification

## Objective

Use one digest-pinned, task-unique Docker lab to qualify the extension's real password-session contract over loopback, actual SSH forwarding, a short-lived HTTPS/WebSocket edge, and an actual Muxy SSH workspace, then prove complete teardown.

## Tasks

1. Define digest-pinned Hermes 0.20.2, OpenSSH 10.3p1, deterministic model, and cloudflared 2026.8.2 services on one Compose network.
2. Generate task-local password hash, HMAC secret, SSH key, verifier challenges, config, and ephemeral ports beneath a mode-0700 root.
3. Wait on service and edge health rather than log timing; expose only bounded error classes and task identifiers.
4. Exercise password success/failure, cookie rotation, fresh/rejected ticket behavior, WebSocket open/reconnect, operations, schedules, board, agent/control scenarios, actual `ssh -L`, and trusted HTTPS.
5. Connect Muxy to the lab's real SSH service, execute the native UX/session/restart matrix, and capture marketplace screenshots only from those actual running surfaces.
6. Tear down all owned processes/resources and emit a digest-only receipt after absence checks.

## Verification

- No raw credential, workspace path, tunnel hostname, or prompt body persists in source, receipt, UI capture, or dist.
- Every claimed topology uses its real mechanism; simulations cannot earn support.
- Owned containers, network, volumes, listeners, tunnel/SSH processes, keys, secrets, and temporary root are absent after teardown.
