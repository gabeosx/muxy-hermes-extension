## Deferred Topology

Muxy SSH workspaces are explicitly unsupported in `0.1.0`. On Muxy 1.5.0 (945), the remote executor fails `posix_spawn("/usr/bin/ssh")` before Hermes receives a request. The extension turns that bounded failure into actionable unsupported guidance. The native reproducer remains opt-in, cannot attest support, and is tracked in `OPEN_ISSUES.md` with full acceptance criteria.

This is not counted as a broken `0.1.0` integration path because it is no longer inside the frozen beta contract. It must not be advertised as supported until the Later issue closes.
