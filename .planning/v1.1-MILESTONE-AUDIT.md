## Explicit Exclusion

Muxy SSH workspaces are not supported by `hermes-agent@0.1.0`. Users must run Muxy locally and use an operator-owned `ssh -L` forward or a trusted HTTPS Dashboard. The extension fails safely if Muxy's remote SSH executor produces the known spawn failure. This exclusion is documented in the README, both product surfaces, qualification commands, and `OPEN_ISSUES.md`.
