| simulation metadata → executable runner | Declarative labels select fixed test cases but never become observed outcomes by themselves. |
| task-owned TLS proxy → pinned Gateway | Bearer and event bytes are transient; proxy accepts only fixed routes and exact test origins. |

| simulation receipt → public evidence | Passing behavior remains support-ineligible and forced Unverified. |
