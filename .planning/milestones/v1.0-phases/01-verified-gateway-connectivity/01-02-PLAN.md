## Trust Boundaries

| Boundary | Description |
|---|---|
| user/DOM → probe coordinator | Credentials and retries enter concurrent state transitions. |
| probe coordinator → GatewayClient | Safe state depends on one owned direct request lifecycle. |
| raw capability/error data → UI | Untrusted remote values cross into rendered and copyable DOM. |
| fixture observations → exact-origin verdict | Only controlled evidence may narrow an otherwise opaque browser failure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Information disclosure | probe snapshots and DOM | high | mitigate | Safe view models exclude bearer, raw request/response data, and content; tests cover retest/abort races. |
| T-01-02 | Elevation of privilege | origin outcome | high | mitigate | UI never infers exact CORS; only harness-observed exact, stable, non-null origin evidence can pass. |
| T-01-03 | Tampering / Information disclosure | URL policy | high | mitigate | Retain Plan 01 non-loopback HTTPS gate and ordinary certificate validation with no exception control. |
| T-01-04 | Elevation of privilege | capability-driven UI | high | mitigate | Capabilities are read-only in this phase; no unknown/absent flag creates a control, helper, permission, or topology branch. |
| T-01-05 | Information disclosure | diagnostics/copy surface | high | mitigate | Normalize to enumerated safe failure classes and omit raw payloads, headers, endpoint details, workspace data, and stack traces. |
</threat_model>
