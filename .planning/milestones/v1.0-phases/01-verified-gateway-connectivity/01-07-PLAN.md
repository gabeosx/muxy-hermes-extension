<interfaces>
Current production contracts to preserve and extend:

- `HermesGatewayPanel.release()` currently calls only `ConnectionProbe.abort()` and clears the token synchronously.
- `ConnectionProbe.abort()` currently aborts its local `AbortController` without calling `GatewayClient.teardown()`.
- `GatewayClient.teardown()` currently increments a generation only; `GatewayClient.probe()` calls `CurlRelay.requestJson()` and `CurlRelay.streamJournal()`.
- `CurlRelay.streamJournal()` currently awaits `muxy.exec`, subscribes to `file.changed`, and scrubs/removes its journal in `finally`.
- Muxy's current page API exposes `muxy.execAsync(argv, options) -> { id, result, cancel() }`; cancelling rejects `result` with `code === "cancelled"` or `cancelled === true` and uses the existing `commands:exec` permission.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|---|---|
| panel close → async relay ownership | A close signal must terminate bearer-backed subprocess work before orderly ownership release. |
| curl result → diagnostic state | Exit codes, HTTP status, and raw error surfaces cross into user-visible classification. |
| journal bytes → cleanup | Content-bearing bytes must be drained only for parsing, overwritten, and removed from the fixed extension root. |
| source/build → executable dependency set | This gap closure must use the existing Muxy and browser APIs without adding packages. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-07-01 | Information disclosure | panel/probe/client/relay teardown | high | mitigate | Await execAsync cancellation through every owner, clear bearer references after settlement, and verify scrub-before-remove on close. |
| T-01-07-02 | Denial of service | repeated close/retest and pending reads | medium | mitigate | Use idempotent release/cancel promises, attempt invalidation, and serialized replacement probes. |
