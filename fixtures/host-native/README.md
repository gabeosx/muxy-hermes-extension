# Host-native qualification fixture

The qualification runner owns this fixture only. It starts a tagged Hermes executable on loopback with a new temporary `HERMES_HOME`, an empty workspace, and a runtime-only API key. The panel never imports this directory, receives no process authority, and sees only the loopback URL plus the one-time token entered by the operator.

Before a support claim, resolve current stable releases, capture the Muxy panel preflight origin, configure that one exact non-null origin, and complete two newly opened panel sessions. If GitHub's release-to-commit API times out, the resolver accepts only the official annotated-tag peel returned by `git ls-remote`; a release name or `target_commitish` is never a revision fallback. The stream request is the fixed harmless `HERMES_STREAM_QUALIFICATION_V1` contract from `COVERAGE.md`; raw prompts, deltas, headers, origins, URLs, and tokens are not durable evidence.
